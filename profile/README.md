## What is MINUS ONE?

MINUS ONE builds tools for security assessments and penetration testing, made for small teams.

## 🧰 Products

| Product | What it is |
| --- | --- |
| [Pentest Dashboard](https://github.com/0xFF-MinusOne/Minus-One) | Vulnerability-management dashboard where a small team shares one workspace. Only the title, severity and progress of a finding go to the cloud; reproduction steps for unreported vulnerabilities stay on your own machine. |

## 🧪 Principles

1. **Sensitive details stay local.** The cloud holds only what is needed to track progress.
2. **Access is enforced in the database,** not only on the screen, and two-factor authentication is required.
3. **Authorized testing only.**
