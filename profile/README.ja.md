## MINUS ONE とは

MINUS ONE は、独立したホワイトハットの活動です。コンセプトは**「民間企業にたよらない脆弱性対策」**です。

脆弱性を見つけて直す仕事は、ふつうセキュリティ企業に任されています。MINUS ONE は会社ではなく、会社の代理でもありません。有志が脆弱性を見つけ、直せる立場の人に非公開で報告し、そのために必要な道具を自分たちで作ります。

## 🧰 道具

| 道具 | 内容 |
| --- | --- |
| [Pentest Dashboard](https://github.com/0xFF-MinusOne/Minus-One) | 脆弱性を管理するダッシュボードです。少人数のチームで 1 つの作業場所を共有します。クラウドに置くのは検出事項のタイトル、深刻度、進み具合だけで、未報告の脆弱性の再現手順などは手元で管理します。 |

## 🧪 方針

1. **独立しています。** 会社ではなく、どのセキュリティ企業にも属しません。
2. **機密の詳細は手元に置きます。** クラウドには、進み具合を追うのに必要なものだけを置きます。
3. **まず非公開で報告します。** 相手は、問題を直せる立場の人です。
4. **許可を得た検査だけを行います。**
